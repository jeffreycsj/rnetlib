# 端点终止退出收尾

状态：用户已确认。监听致命退出时关闭该端点及全部所属会话，其他端点不受影响。

## 范围与契约

- UDP/KCP 客户端连接终止失败应注销端点，释放会话、待认证和排队额度；候选地址切换不是终止失败。
- TCP 保持当前 accept 错误终止策略，补齐端点及所属会话清理。可恢复错误分类/退避另行实施。
- 与 close/stop 竞态只允许一个清理赢家；故障通知被拒绝也不影响资源回收。
- 路由仍存在且队列允许时，待连接客户端保留 JoinFailed 在 SessionClosed 前的顺序，不重复失败通知，不误报已建立会话；若事件背压已先关闭会话，不补造第二次通知。
- 游戏层包含零容量的 poll 应清除失效端点的策略与暂存状态。
- 不改 wire/ABI，不实现跨实例恢复，不启动长稳；保留已有工作区修改。

基线为传输层 43 项、候选切换 2 项、游戏端点回收 2 项，全部通过。本轮新增 8 个测试函数；关键缺陷经过实际行为 RED/GREEN，最终传输层单元测试 48 项。真实 socket 故障用例限 Linux。

客户端握手超时统一由端点所有者处理，移除维护循环重复的客户端超时检查，避免同一轮内跨过时间阈值而先删会话、后漏端点。TCP 子任务集合优先回收已完成任务；正常 drain 不取消存活任务，端点显式关闭或致命退出才取消。
