# 单一现行接口与协议实现

状态：用户已确认 API/ABI 与 wire 一起统一，保留业务版本协商，不兼容旧 SDK；实施中。

## 目标与约束

只维护一套现行 API/ABI 配置、事件、指标和日志布局，不再保留 v1/v2/v3/v4/v5 接口、转接层、旧符号别名或可选兼容开关。允许破坏旧源码与二进制兼容性，SDK、头文件和 native 库必须整体重新编译部署。保留工作区已有 TCP 生命周期修复，不提交或覆盖用户变更。

游戏门面和底层传输接口职责不同，不因去版本化而删除其中一层；两层各自只有一套现行入口。保留 TCP/UDP/KCP、同库服务器/客户端、域名连接、服务器动态切换业务加密、认证控制通道、业务授权、恢复、LatestOnly、调度、质量/时钟采样、结构化日志及 P95/P99 等现有能力。

不做跨实例恢复；长稳压测仍在功能收尾之后。明文业务模式不等于旧式无认证连接，不能一起删除。

## 删除与合并清单

| 当前重复/兼容路径 | 目标 |
| --- | --- |
| `RnetConfig`、`RnetConfigV3/V4/V5` 及逐层字段转换 | 一套 `RnetConfig`，包含现行资源预算、超时、socket、安全及日志配置 |
| `rnet_runtime_create[_v2/_v3/_v4/_v5]` | 一个现行 `rnet_runtime_create`，客户端身份/信任可选，日志通过统一配置提供 |
| `RnetLogger` / `RnetLoggerV2` | 一套结构化 `RnetLogger`，保留时间、上下文和有界回调语义 |
| 多套 metrics / latency 布局和查询 | 无版本后缀的完整指标布局，保留 P99.9、准入拒绝原因及关闭原因计数 |
| `RnetGameConfig` / `RnetGameConfigV2`，四种 game create 入口 | 一套完整 game config 和 create，包含实时/优先级队列预算及可选 logger |
| `RnetGameEvent` / `RnetGameEventV2` 及双 poll | 一套完整事件和返回 status + count 的 poll，保留 correlation 及 buffer token 所有权 |
| 旧 `endpoint_open` / `listener_open` / `client_join`、transport-specific Rust 构造器 | 只保留配置中选择 transport 的 `listen` / `connect` 主路径及域名/地址解析辅助入口 |
| 旧无认证 TCP/UDP、旧 secure TCP/UDP/KCP 实现与允许旧端点开关 | 删除仅供兼容的执行分支和实现模块；共享的 cookie/KCP/Noise 能力保留或迁移至现行实现 |
| `send_legacy`、公开 msg_type/stream_id 参数 | 删除兼容发送入口；保留 opaque payload 和功能性的可选 send options |
| SDK 内的旧配置重载、P/Invoke/cgo 适配、示例、导出名单、fuzz/结构门禁 | 一起迁移，不保留转发别名；功能测试迁移到新接口，不能靠删除测试制造全绿 |

## wire 范围：已确认一起统一

基于现有范围协商流程统一游戏建连，精确业务版本表示为 min=max；普通/恢复建连均走同一现行协议实现。删除旧精确 wire-v3 的编码、解码和状态机路径，合并公开 range/exact 配置及入口。业务协议 ID、业务版本范围、构建信息、能力元数据与就绪前授权继续保留；这是业务兼容协商，不是库的多版本实现。用户已确认此范围，不再保留“仅清理 ABI”的分支方案。

保留一个现行 wire 标识并显式拒绝不支持的数据包，不将历史标识随意重新编号为 1。只为旧调用接口保留的消息头字段在确认 wire 范围后清理；网络控制 kind 与必要的 correlation/sequence/tick 不受影响。

## 安全与调用契约审查

- 本次是用户授权的破坏性变更，不需要弃用期或兼容桥接；不能对旧客户端承诺互通。
- ABI 标识不是兼容入口。现行 ABI 标识需与旧布局区分，SDK 在初始化/创建前检查库标识，保留结构体大小校验。FFI 配置读取先验证可读公共头及完整布局大小，再读其余字段，避免先读完整新结构体再检查旧尺寸。
- 保持错误码、事件内存释放规则、日志回调可重入查询/禁止销毁、密钥清理和线程安全契约；poll 不混淆零事件与错误。
- 移除旧无认证入口不会移除服务器控制的业务明文模式；Noise 授权和控制完整性仍必须存在。
- 普通断线与端点故障继续区分，客户端独占端点退出回收、服务端共享监听保留。
- AIP 兼容性/命名/错误契约检查适用于此次设计；REST 资源名、HTTP 方法、分页等不适用于本地网络库 ABI，不为套规范增加新抽象。
